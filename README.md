 # HilfeNetz

HilfeNetz ist eine Plattform zur Vermittlung von Nachbarschaftshilfe.

## Projektziel

Entwicklung einer sicheren und benutzerfreundlichen Anwendung zur Vermittlung freiwilliger Hilfe zwischen Menschen.

## Projektstruktur

- Lastenheft
- Pflichtenheft
- Dokumentation
- Prototyp
- Ressourcen
- Tests

Projektstart: Juli 2026
